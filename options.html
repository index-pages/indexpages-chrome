What this key allows

    Create a key in the dashboard under Settings → API keys. It is shown only once, so paste it here right away.

    Which scopes to give the key

    When you create the key in the dashboard you tick its scopes. The extension uses each one for one thing and hides what the key cannot do.

    ScopeUsed for
    balance:readShowing the balance and the price per URL, and checking the cost before a run.
    orders:readListing recent orders with their status and progress.
    orders:writeCreating drafts from your URL list and deleting drafts.
    orders:runRunning a draft. This spends your balance.

    Recommended: a key without orders:run

    If you only want to collect URLs into drafts and decide on payment in the dashboard, create a key with balance:read, orders:read and orders:write and leave orders:run unticked. Such a key cannot spend money, even if it leaks.

    With orders:run, every run still asks you to confirm the cost first.

    Privacy

    • The key is kept in this browser’s local extension storage. It is not synced to other devices.
    • The key and the URLs you choose to send go only to api.index-pages.com.
    • No analytics, no tracking, no browsing history. The extension reads a page’s address only when you ask it to.
